# 键政

这是一个关于政治与公共事务的写作仓库。题目多半起于读书、时事和日常讨论，写成什么样子由内容决定，随写随收，持续更新。

除了原创作品，阅读中留存的他人文章、言论与报道也归档在这里，作为写作的依据和事件的记录。这部分逐篇标明原作者与出处，不与原创混在一起。

## 收录范围

- 美国政治与海外华人的政治生态
- 威权体制、国家能力与政治文化
- 移民、教育、劳工等公共政策
- 更理论化的法律与政治哲学议题

以上分类会随内容增减。凡是与公共生活有关的话题，都可能出现在这里。

## 形式

内容的形式不固定，可能是长文、短评、札记、纪念文字，也可能是互动工具、图表或资料整理。文字多用 Markdown，需要交互的内容做成可直接在浏览器里运行的 HTML。

## 使用

**在线阅读**

Markdown 文件在 GitHub 网页上会直接排版显示，点开即可阅读。HTML 文件在 GitHub 上只显示源码，需要下载到本地后打开。

**下载单个文件**

打开文件页面，点右上角的下载按钮（Download raw file），保存到本地即可。

**获取整个仓库**

```bash
git clone https://github.com/Taoshuke/jianzheng.git
```

之后要同步最新内容，在仓库目录里运行

```bash
git pull
```

不使用 Git 的话，也可以在仓库首页点 Code，再选 Download ZIP 下载压缩包。

**打开互动工具**

HTML 文件双击即可在浏览器中打开，不需要安装任何软件，也不需要搭建服务器。工具不上传任何数据，答题记录只留在你自己的浏览器里，关闭页面即清除。

**引用与转载**

引用请注明出处，并附上原文链接。

## 立场

我的立场偏向进步主义，认为平等与个人自由可以靠制度改良一步步扩展，权力需要受约束，少数人的权利需要保护。

把立场摆明，是为了让读者知道这些文字从哪里出发，并不意味着结论先于论证。分析仍以证据为准，对同一阵营的说法同样追问它能否自洽、在哪里失效。欢迎通过 Issue 提出异议或补充材料。
